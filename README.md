\# Python Software Engineering Evaluation Toolkit



A practical collection of Python software engineering tasks designed to demonstrate debugging, bug fixing, automated testing, and reference solution development.



\## Project Overview



This project explores how software engineering tasks can be designed and evaluated consistently.



It includes buggy implementations, test cases, problem descriptions, and golden reference solutions.



\## Objectives



\- Develop realistic software engineering challenges.

\- Identify and fix programming bugs.

\- Build automated tests using Pytest.

\- Create reliable reference solutions.

\- Validate expected and invalid inputs.

\- Practise reproducible software testing.



\## Technologies



\- Python 3.11

\- Pytest 9.2.0

\- Git

\- GitHub
