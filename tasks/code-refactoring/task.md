\# Code Refactoring Challenge: User Validation



\## Problem Description



The user validation code contains duplicated logic and is difficult to maintain.



\## Objective



Refactor the code to improve readability, maintainability, and reusability without changing its expected behaviour.



\## Requirements



1\. Remove duplicated validation logic.

2\. Use clear and meaningful function names.

3\. Separate validation responsibilities.

4\. Handle invalid inputs consistently.

5\. Preserve the existing expected behaviour.



\## Acceptance Criteria



\- Valid user details are accepted.

\- Invalid user details are rejected.

\- Validation logic is reusable.

\- Existing functionality is not broken.

\- Code is readable and maintainable.
