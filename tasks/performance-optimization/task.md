\# Performance Optimization Challenge: Duplicate Detection



\## Problem Description



The current duplicate detection function uses nested loops, making it slow when processing large lists.



\## Objective



Optimize the function to identify duplicate values efficiently.



\## Requirements



1\. Identify duplicate values in a list.

2\. Avoid unnecessary nested loops.

3\. Preserve the original input.

4\. Return each duplicate only once.

5\. Handle empty lists.

6\. Support large input lists.



\## Acceptance Criteria



\- Duplicate values are identified correctly.

\- Each duplicate appears only once in the result.

\- Lists without duplicates return an empty list.

\- Empty lists are handled correctly.

\- The optimized implementation should use an efficient data structure.
