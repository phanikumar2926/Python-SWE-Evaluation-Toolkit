\# Feature Development Challenge: Task Manager



\## Problem Description



Create a simple task manager that allows users to manage their daily tasks.



\## Objective



Implement functions to add, complete, and list tasks.



\## Requirements



1\. Add a new task.

2\. Prevent empty task descriptions.

3\. Mark an existing task as completed.

4\. List all tasks.

5\. Handle tasks that do not exist.

6\. Maintain task status.



\## Acceptance Criteria



\- New tasks are added successfully.

\- Empty task descriptions are rejected.

\- Tasks can be marked as completed.

\- Task status is updated correctly.

\- All tasks can be listed.

\- Missing tasks are handled appropriately.
